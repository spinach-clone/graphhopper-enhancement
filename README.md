# 🚀 GraphHopper Enhancement (Team IntelleX)

## 📌 Project Overview
This project enhances the GraphHopper API exploration codebase as part of a social coding activity. Instead of building from scratch, our team transformed an existing CLI-based application into a modern, secure, and user-friendly system, featuring a graphical interface, interactive map visualization, and improved data security practices.
---

## 🎯 Objectives
- Transform a CLI-based program into a **Graphical User Interface (GUI)**
- Improve **user accessibility and experience**
- Integrate a **map visualization system**
- Enhance **security practices** (protect sensitive data)
- Implement **UI improvements** such as themes and readability features

---

## ✨ Features
- 🖥️ GUI built using **PyWebView**
- 🗺️ **Interactive Map API Integration** for route visualization
- 🌗 **Dark/Light Mode Toggle**
- 🧹 Clean and structured output display

--- 

## 🧱 Tech Stack
- Python
- PyWebView
- Map API (for route visualization)
- Git & GitHub (for collaboration)
